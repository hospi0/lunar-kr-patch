# 번역 규칙·용어집

## 작업 방법
- 대사: `work/text/scr.tsv` 4열 KO. 조각 파일(«번호<TAB>KO»)을 `python tools/koapply.py 조각.tsv` 로 넣는다(같은 JP 중복 대사는 자동으로 같이 채움).
- UI: `work/text/ui.tsv` 6열 KO. 조각 파일을 `python tools/uiapply.py 조각.tsv` 로 넣는다(같은 JP 빈 칸 자동 채움). 쓴 글자 그대로 들어가므로 전각·반각은 직접 고른다.
- 검사: `python tools/kocheck.py [S03]` — 제어 순서·줄 길이·쪽 줄 수·글자·UI 예산, 끝에 진행률과 한글 음절 수(글꼴 칸 약 1,500 이하).
- `tools/scr.py`·`tools/exestr.py` 로 다시 뽑아도 KO 는 (번호/위치, JP) 가 같으면 살아남는다.

## 표기 규칙
- 제어: `{08}`(대기)·`{0c}`(새 쪽)는 **순서·개수를 원문 그대로**. `{0d}`(연출 쉼)는 말투에 맞게 옮겨도 된다. `\n` = 줄바꿈.
- **한 줄 16칸**(한글·부호·빈칸 모두 1칸). 쪽({0c} 사이) 줄 수는 원문 이하.
- 띄어쓰기는 보통 빈칸 ` ` (빌드 때 전각 빈칸으로 바꿀지 결정). 원문의 전각 빈칸(구절 끊기)은 한국어 띄어쓰기로 대신한다.
- `♥` = 원문 `曖`(KANJI.FNT 9E42 자리에 그린 하트). KO 에서는 ♥ 로 쓴다.
- 말줄임 `……`·`…`, 물결 `～`, 느낌표·물음표는 전각 그대로(！？). 숫자는 전각.
- 어린이 대상 게임 → 쉬운 말, 한자어 남발 금지. 말투는 인물별로 일관되게.

## UI 규칙
- 예산은 **바이트**: W 는 한글·전각 2, ASCII(빈칸·`%3d`·숫자·`\n`) 1, `{09}` 1. H(8×8 반각)는 글자당 1.
- 앞의 `{09}` 는 그대로 둔다(자리 맞춤 바이트). 장 번호·원문의 반각 빈칸은 가운데 맞춤용 — 예산 안에서 살린다.
- 잡음(ｯｹ·ﾌﾌ 같은 2바이트 조각)·`ＭＰ:%3d/%3d`·`ＨＰ` 는 `=`(원문 그대로).
- 나뉜 문장(세이브 RAM 안내 등)은 조각끼리 이어 읽히게 나눴다: «본체ＲＡＭ이 준비되어 / 있지 않음．», «Ｌ버튼 또는 Ｒ버튼을 누른 채 / 리셋 버튼을 누르면 저장 데이터 / 관리 화면으로 갑니다．».
- 마법 설명 머리: 単体 단일 · 全体 전체 · 範囲 범위 · 方向 방향 · 周囲 주위 · 自分 자신. 剣技 검술, 素早さ 민첩성, 耐魔法力 내마법력(耐魔力 내마력).
- 장 제목: 옌과 청룡 · 별 보는 힘 · 봉인의 문 · 비밀신입생 · 전격대작전(２) · 인어 보석 · 유령섬 · 필살！합체마법 · 마녀바르아 · 바다 위 학원 · 이야기의 시작 · 안녕 마법학원. 따로 쓰는 장 번호는 «제１２장», 제목과 붙은 것은 «１２장 …»(예산).
- **반각(8×8) 한글 음절 126개** — 1바이트 칸(가나 약 128 + 빈 칸) 안. 늘리지 말 것(kocheck 끝의 «반각 음절»).

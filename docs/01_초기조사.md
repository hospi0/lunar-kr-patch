  대사 끝 = NUL(대개 `08 00` = 대기+끝, 선택지 등은 NUL 만), 대사 안 `0C` = 새 쪽, `0D` = (연출용) , `0A` = 줄바꿈.
  예: S00 구역 0x800 머리 +0x38 = (0x28, 0x26C) → 대사 39개.

### 8×8 글꼴(ASCII.FNT) 쓰임
- 0xA0‥0xDF = 표준 반각 가타카나, 0x86‥0x9F·0xE0‥0xFD = **게임 전용 1바이트 히라가나**.
- 실제 1바이트 가나 문자열은 실행 파일에만: `/1` 인물 이름 7개(ｸﾞﾚﾝ·ｱｽﾞ·ｳｨﾝ·ﾌﾞﾚｰﾄﾞ·ｾﾆｱ·ﾚﾅ·ｴﾘｰ — 메뉴 캐릭터 아래 이름),
  `/2` 마법·기술 이름 **반각판 약 60개**(전각판과 짝: イヤシ/ｲﾔｼ … ｼﾞｬｯｼﾞﾒﾝﾄﾃﾞｲ) — 반각판이 어느 화면(전투?)에 나오는지 확인 필요.
- ⚠️8×8 한글 = 칸 128·7×7 판독 한계. 마법 이름 반각판까지 한글로 하면 음절 수가 많다 → 쓰이는 화면 보고 결정.
- (2026-09-26 스샷 6) 반각 마법 이름 = **마법 목록**(«ﾔｽﾗｷﾞ 4», MP 옆, 8×8). 고르면 위에 전각 이름·설명이 16×16 으로 따로 나온다. 인물 이름(ｴﾘｰ·ﾚﾅ)도 8×8.
  ★사용자 결정: **반각 마법 이름도 먼저 제대로 번역 → 음절 수를 세서 8×8 칸(1바이트 가나 약 128 + 안 쓰는 영소문자·기호 칸)을 넘으면 그때 줄인다.** 7×7 로 그려도 칸 수는 안 늘어난다(한계 = 1바이트 코드 256).
